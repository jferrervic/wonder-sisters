# Wonder Sisters: Pequeños grandes problemas

Videojuego de plataformas 2D desarrollado en **Godot 4.7** como Trabajo Final de Grado (TFG) de la **Universitat Oberta de Catalunya (UOC)**.

Laia y Enara son dos hermanas que tienen que superar juntas los "pequeños grandes problemas" de su día a día. Cada hermana tiene habilidades distintas y solo cooperando pueden llegar al final de los nivel.

## Estado del proyecto

**Prototipo jugable (PEC 2).** El proyecto está en desarrollo.

Incluye:
- Control de las dos hermanas y cambio entre ellas.
- Laia: Salta más alto y puede empujar objetos.
- Enara: Más rápida y puede rodar dando volteretas para pasar por huecos pequeños.
- Menú de título, menú de pausa (continuar, reiniciar, salir) y escena de créditos.
- Meta final: El nivel termina cuando las dos hermanas llegan juntas.

## Controles

| Acción | Teclado |
|---|---|
| Moverse | A / D o flechas izquierda / derecha |
| Saltar | Espacio, W o flecha arriba |
| Hacerse bola (Enara) | S o flecha abajo |
| Cambiar de hermana | Q |
| Pausa | Esc |

## Cómo jugar

**Opción 1: ejecutable (Windows)**
Descarga la última versión desde el apartado **Releases** de este repositorio y abre el archivo `.exe`.

**Opción 2: desde Godot**
1. Instala [Godot 4.7](https://godotengine.org/download).
2. Clona o descarga este repositorio.
3. En Godot, pulsa **Importar** y selecciona el archivo `project.godot`.
4. Pulsa **Play** o **F5** para jugar.
